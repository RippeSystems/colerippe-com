# Cole Rippe Personal Landing Page

A static, responsive personal landing page built around the uploaded Cole Rippe AI motion loops.

## Preview locally
Open `index.html` directly, or serve the folder with any static web server.

## Deployment
The folder is ready for static hosting through Cloudflare Workers Static Assets.

## Content / links
The current public calls-to-action point to Instagram and YouTube at `@colerippe`.

## Video strategy
The 2160×2160 source loops were transcoded to lightweight 720×720 H.264 MP4s for faster web playback. The hero is locked to the opening takeoff sequence from loop 12 and restarts before the aftermath. The remaining visual loops lazy-load in the reel section.
